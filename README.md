Project Overview
Green Horizons Eco-Tours is a responsive eco-tourism website designed to promote sustainable travel experiences across South Africa. The website allows users to explore tour packages, learn about the company, read eco-tourism blog content, make bookings, submit enquiries, and contact the organization.

The website focuses on user experience, accessibility, responsiveness, SEO optimization, and interactive functionality using HTML, CSS, and JavaScript.
